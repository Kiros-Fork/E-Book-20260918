GPT‑6 Astra 發布後，中國 AI 圈很快出現一種說法：美國終於找到「反蒸餾」的方法，中國模型要追趕前沿模型會變得更困難。
我認為方向大致正確，但重點並不是 OpenAI 突然發明了某種反蒸餾架構。
Astra 真正值得注意的變化，是前沿模型的能力愈來愈難被還原成一段外部可以觀察、複製的自然語言推理軌跡。
OpenAI 公布的 system card 顯示，Astra 在不使用 CoT 的條件下，能完成比前代困難得多的任務。UK AISI 在其測試口徑下，估計 Astra 的無 CoT 數學任務能力，從 GPT‑5.6 Sol 的3.6分鐘提高到30.9分鐘；它的原始 CoT 也更壓縮、更難閱讀，而且更能控制自己表達出來的推理內容。
但這還不能證明 Astra 採用了某種新的「不可見推理架構」。OpenAI 從 o1 開始就沒有向使用者開放原始 CoT，而 Astra 官方也沒有披露 latent reasoning 或循環計算等架構變化。
更準確的說法是：模型表現出來的能力，開始不再忠實地映射到它寫出來的推理文字。
這對蒸餾確實有影響。
如果外部實驗室拿不到原始 CoT、完整的 reasoning summary、每一步的 logits，也無法無限制地呼叫 API，那麼依靠「問題—推理過程—答案」複製老師能力的邊際收益就會下降。再加上 API 權限、異常流量辨識、跨帳號關聯和反模型提取機制，黑盒蒸餾的成本會繼續上升。
但蒸餾不會因此消失，它只會換一種形式。
新的方法不是照抄老師寫出來的思考過程，而是讓前沿模型生成合成任務、比較候選答案、提供偏好訊號、建立測試環境，再由自己的模型透過 Verifier、環境回饋和強化學習形成能力。
中國頭部實驗室公開的技術路線，其實已經朝這個方向前進。
DeepSeek‑V4 先進行32T至33T token 的自主預訓練，再分別訓練數學、程式碼、Agent 等領域專家。容易驗證的任務使用規則或測試案例，困難任務使用 Generative Reward Model，最後再用十多個內部教師模型進行 On‑Policy Distillation。
Qwen 正在大量使用合成資料、可執行程式碼任務和環境回饋；GLM‑5 建立了非同步 RL 基礎設施；Kimi 則繼續擴大基礎模型、長程 Agent 和 Parallel-Agent RL。
它們與 Astra 的表現形式並不完全相同。DeepSeek‑V4 仍然透過增加 reasoning tokens 提升能力，Kimi K3 也仍會向 API 使用者返回 reasoning_content。中國模型並沒有集體放棄顯式 CoT。
真正一致的是另一件事：中國實驗室正在降低對外部 CoT 的單點依賴，建立自己的預訓練、專家模型、Verifier、合成資料、RL 和執行環境。
這也會改變算力產業的受益邏輯。
需求增加不代表所有 IDC 都能漲價，稀缺的也不只是傳統意義上的「訓練算力」。未來需要大量算力的，還包括 RL rollout、Reward Model、Verifier、合成資料生成、Agent 沙箱，以及高強度 reasoning inference。
真正稀缺的是可以同時交付電力、高密度供配電、液冷、集群網路、儲存、調度系統與模型適配的 AI Factory Ready Capacity。
而且，這也不是單純堆疊更多 GPU。DeepSeek‑V4 已經在 NVIDIA GPU 和華為昇騰 NPU 上驗證通訊與計算重疊方案，說明模型架構、算子庫、編譯器和集群硬體之間的共同最佳化，可能比單一晶片的標稱算力更重要。
當前沿能力不再能從一段 CoT 中直接複製，中國實驗室下一步要證明的，可能不是它還能不能蒸餾，而是能不能把開源模型的優勢，從輸出層推進到一套完整、自主的訓練與回饋閉環。
