# rurl v0.1.0 — Phase 1

一個用 Rust 實作的 curl 替代工具，提供非同步、型別安全的 HTTP/HTTPS 請求。

## 功能一覽

Phase 1 涵蓋基礎 CLI 解析與 HTTP 請求：

- **GET/POST/PUT/DELETE/HEAD/PATCH** 六種方法，`-X` 指定並支援大小寫不敏感（`-X GET` / `-X get`）
- **自訂 Header**：`-H "Name: Value"`（可重複使用）
- **Body 傳送**：`-d` / `--data`；提供資料但未指定方法時自動升級為 POST
- **重新導向**：`-L` 跟隨重導向（最多 20 次）；預設不跟隨
- **Timeout**：`-m` / `--max-time`（秒）
- **回應標頭**：`-i` 在 body 前印出 HTTP 狀態行與標頭
- **詳細日誌**：`-v` 輸出請求 method/url/headers 至 stderr
- **輸出至檔案**：`-o` / `--output` 將 body 存檔

## 技術選型

| 套件 | 用途 |
|------|------|
| `clap` (derive) | CLI 參數解析 |
| `reqwest` | 非同步 HTTP 客戶端（TLS + 內建 redirect 策略） |
| `tokio` | 非同步執行環境 |
| `anyhow` | 錯誤處理 |

## 使用方式

```bash
# 基本 GET
./target/debug/rurl https://api.github.com/users/octocat

# 指定方法與自訂標頭
./target/debug/rurl -X POST https://httpbin.org/post \
    -H "Content-Type: application/json" -d '{"name": "rust"}'

# 跟隨重導向、逾時 10 秒、包含回應標頭
./target/debug/rurl -L -m 10 -i https://example.com

# 存檔並顯示詳細訊息
./target/debug/rurl -v -o page.html https://example.com
```

## 設計重點

- `cli.rs` 的 `infer_method()`：提供 `-d` 時自動由 GET 升級為 POST，貼近 curl 行為。
- `client.rs` 以 `Client::builder()` 統一處理 timeout 與 redirect 策略。
- verbose 日誌輸出至 **stderr**，不污染 stdout 的 body 資料。

## 測試

`./test.sh` 涵蓋 11 個步驟、22 項斷言：編譯/lint、版本輸出、方法正確性、Header/Body、轉址、逾時、標頭顯示、檔案輸出。需要網路的測試預設使用 `http://httpbin.org`，可透過 `BASE` 環境變數覆寫。
